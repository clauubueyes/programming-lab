# Even or Odd

## Description

Create a program that asks the user for a number
and determines whether it is even or odd.

## Requirements

- Ask the user for a number.
- Determine whether the number is even or odd.
- Display the result.

## Examples

Input:
7

Output:
7 is odd

## What I learn: 
1. The % operator returns the remainder of a division.
2. A number is even when the remainder of dividing it by 2 is 0.
3. try/except can be used to handle invalid user input.
4. ValueError occurs when trying to convert invalid input to an integer.
5. A function should have a clear responsibility.
6. es_par() can determine whether a number is even without handling user input or displaying anything
