# 🧑‍💻 Programming Lab

Repositorio personal para aprender programación desde los fundamentos hasta el desarrollo de proyectos completos.

La idea de este repositorio es aprender **programando**, no simplemente siguiendo tutoriales. Cada ejercicio y proyecto está pensado para introducir nuevos conceptos, practicar buenas técnicas y aumentar progresivamente la dificultad.

## 🎯 Objetivos

* Aprender a resolver problemas mediante código.
* Consolidar los fundamentos de programación.
* Aprender buenas prácticas y escribir código mantenible.
* Practicar algoritmos y estructuras de datos.
* Aprender testing y debugging.
* Familiarizarme con Git y GitHub.
* Aprender desarrollo backend y frontend.
* Explorar bases de datos y APIs.
* Introducirme progresivamente en Data Science y Machine Learning.
* Construir proyectos cada vez más completos.

## 🧠 How I Learn

Los proyectos siguen una progresión:

**Concept → Exercise → Mini Project → Refactoring → Testing → Bigger Project**

La prioridad no es únicamente conseguir que el código funcione, sino entender:

* por qué funciona,
* cómo dividir un problema,
* qué decisiones de diseño tomar,
* cómo detectar errores,
* cómo mejorar una solución,
* y cómo escribir código que pueda mantenerse y ampliarse.
