## Frecuency Counter 

### Description 
Create a function count_frencuncies(items) that recives a list of items (numbers or strings) and returns a dictionary where the keys are the items and the values are the number of times they are repeated.

### Test 

1. count_frequencies([1, 1, 2, 3, 3, 3]) -> {1: 2, 2: 1, 3: 3} 
2. count_frequencies(["drama", "acción", "drama", "comedia"]) -> {"drama": 2, "acción": 1, "comedia": 1}
3. count_frequencies([]) -> {}
